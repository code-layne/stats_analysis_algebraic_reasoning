\parthead{Part B --- Multiple Choice \hfill 8 questions, 2 points each}

\small
\begin{enumerate}[leftmargin=2.2em, itemsep=5pt, topsep=2pt, start=15]

\item Summit Middle School records each student's \textbf{home ZIP code}
($22301$, $22305$, or $22314$). This variable is
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item quantitative, because you can compute a mean ZIP code.
  \item categorical, because the numbers are labels for places.\correct
  \item quantitative, because the values are numbers.
  \item neither, because a ZIP code is not really data.
\end{enumerate}

% keep each stem with its four options
\boxguard[7]
\item Two volunteers each take an honest random sample of $40$ Pine Valley
Aquatic Center members. One finds that $55\%$ take a class; the other finds
$45\%$. The best explanation is that
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item one volunteer made a mistake, because there is only one true percent.
  \item the true percent must be exactly $50\%$, halfway between them.
  \item the percent of members who take a class changed between the samples.
  \item both are statistics estimating one parameter, and samples vary.\correct
\end{enumerate}

% keep each stem with its four options
\boxguard[7]
\item Each of Hillcrest High School's $36$ advisories holds students from a
\textbf{single grade}. A researcher draws $3$ advisories at random and surveys
everyone in them. The main problem with this sample is that
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item an advisory is alike inside, so at most three grades are reached.\correct
  \item no chance was used, so it is a convenience sample.
  \item three advisories is too small a sample to use.
  \item a cluster sample can never be used in a school.
\end{enumerate}

% keep each stem with its four options
\boxguard[7]
\item Willow Creek Apartments e-mails a survey to a random sample drawn from its
list of e-mail addresses. Households with no e-mail on file can never be reached.
Those households are an example of
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item nonresponse, because they did not answer.
  \item a convenience sample, because the others were easier to reach.
  \item undercoverage, because they could never have been chosen.\correct
  \item sampling variability, because samples differ from each other.
\end{enumerate}

% keep each stem with its four options
\boxguard[7]
\item A survey's method causes it to \textbf{overestimate} by $9$ percentage
points. The researcher repeats it with \textbf{four times as many people} and the
same method. The new estimate will most likely
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item land close to the true value, because the sample is larger.
  \item underestimate, because larger samples pull the other way.
  \item be impossible to predict in any direction.
  \item overestimate by about the same $9$ points.\correct
\end{enumerate}

% keep each stem with its four options
\boxguard[7]
\item In a random sample of teenagers, those who eat breakfast daily score higher
on a memory test than those who do not. Nobody was assigned. This result shows
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item an association only; a lurking variable could explain it.\correct
  \item that eating breakfast causes higher memory scores.
  \item that a good memory causes teenagers to eat breakfast.
  \item nothing at all, because the sample was chosen at random.
\end{enumerate}

% keep each stem with its four options
\boxguard[7]
\item In an experiment on a new allergy spray, the control group is given a
\textbf{placebo} spray. Its purpose is to
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item remove the need for random assignment.
  \item tell each subject which group they are in.
  \item let both groups believe they are treated, so only the spray differs.\correct
  \item make the total number of subjects larger.
\end{enumerate}

% keep each stem with its four options
\boxguard[7]
\item A researcher wants to know whether vaping damages the lungs of
$15$-year-olds. No experiment is run. The best reason is that the experiment would be
\begin{enumerate}[label=(\Alph*), leftmargin=1.8em, itemsep=1pt, topsep=1pt]
  \item impossible, because lung damage cannot be measured.
  \item unethical, because it would assign teenagers to vape.\correct
  \item impractical, because $15$-year-olds are hard to find.
  \item unnecessary, because observational studies prove causation.
\end{enumerate}

\end{enumerate}

\begin{work}

removes.
